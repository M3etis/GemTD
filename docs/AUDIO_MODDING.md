# Как заменить звуки без пересборки

## Коротко

1. Откройте игру → **Настройки → Звук → «Открыть папку звуков»**. Откроется папка звукового пака:
   `~/Library/Application Support/GemTowerDefense/sound_packs/custom/`
2. Каждая папка внутри — одно звуковое событие (например, `sfx/gems/ruby/attack`).
3. Положите в нужную папку один или несколько файлов `.ogg`, `.wav` или `.mp3`.
4. Нажмите **«Перезагрузить звуки»**. Перезапуск игры не нужен.

Если файлов в папке несколько, игра выбирает случайный и не повторяет один и тот же два раза подряд. Пустая папка — играет встроенный звук.

## Порядок поиска

Для каждого события используется первый источник, в папке которого есть аудиофайлы:

| Приоритет | Источник | Когда использовать |
|---|---|---|
| 1 | `--audio-dir=<путь>` в командной строке | быстро проверить пак, не копируя файлы |
| 2 | `<папка рядом с Gem Tower Defense.app>/audio_override/` | «портативный» пак рядом со сборкой (подпись .app не ломается) |
| 3 | `~/Library/Application Support/GemTowerDefense/sound_packs/<пак>/` | основной способ; пак выбирается в настройках |
| 4 | встроенный пак `res://audio` | звуки по умолчанию |

Пример запуска с паком из любой папки — из проекта:

```bash
godot --path . -- --audio-dir=/Users/me/MyGemSounds
```

и из собранной игры:

```bash
"/Applications/Gem Tower Defense.app/Contents/MacOS/Gem Tower Defense" -- --audio-dir=/Users/me/MyGemSounds
```

Портативный пак: папка `audio_override` лежит рядом с приложением, внутри — то же дерево событий:

```
Gem Tower Defense.app
audio_override/
  sfx/ui/click/my_click.wav
  music/combat/my_battle_theme.ogg
```

Внутрь `Gem Tower Defense.app` файлы класть нельзя: это ломает подпись, и macOS откажется запускать приложение.

Если портативный пак не подхватывается, проверьте «Звуковой браузер» или `--audio-report` (строка `portable` в списке источников). Скачанное приложение с карантином macOS запускает из временной копии (App Translocation), и папку рядом с ним игра не видит. Снимите карантин:

```bash
xattr -dr com.apple.quarantine "/Applications/Gem Tower Defense.app"
```

## Добавить свои варианты к встроенным

Положите в папку события файл `_event.json`:

```json
{ "mode": "append" }
```

Тогда ваши файлы **добавятся** к встроенным, а не заменят их.

## Настройки события (`_event.json`)

| Поле | Что делает | Пример |
|---|---|---|
| `mode` | `replace` (по умолчанию) или `append` | `"append"` |
| `volume_db` | громкость в дБ | `-6.0` |
| `pitch_jitter` | случайный разброс высоты (0.05 = ±5 %) | `0.08` |
| `cooldown_ms` | минимальный интервал между проигрываниями | `60` |
| `max_voices` | сколько копий звука может звучать одновременно | `4` |
| `bus` | шина микшера: `SFX`, `UI`, `Ambience`, `Music` | `"UI"` |
| `optional` | событию можно молчать: во встроенном паке файлов нет, звук даёт только пак (`--audio-report` не считает его пропуском) | `true` |

Значения из `_event.json` важнее значений из встроенного `audio_manifest.json`.

## Список событий

Полный список — в `README.txt` в папке пака и в `audio/audio_manifest.json`. Основные группы:

| Папка | Когда звучит |
|---|---|
| `sfx/ui/*` | наведение, клик, подтверждение, ошибка, окна, уведомления |
| `sfx/build/rock_place`, `reveal/q1…q5`, `wall_form`, `invalid`, `path_change` | установка камня, раскрытие гема по качеству, превращение в стену |
| `sfx/choose/keep` | выбор башни |
| `sfx/gems/<гем>/attack`, `…/impact` | выстрел и попадание каждого из 8 гемов |
| `sfx/specials/<спец-башня>/attack`, `impact`, `ability`, `upgrade` | выстрел, попадание, особое умение и улучшение 13 спец-башен |
| `sfx/enemies/<тип>/death` | смерть врагов (у новых типов fallback — `sfx/enemies/normal/death`) |
| `sfx/boss/warning`, `spawn`, `phase_change`, `summon`, `death` | босс: предупреждение, появление, смена фазы, призыв эскорта, смерть |
| `sfx/traits/<трейт>` | срабатывание трейта: rush, blink, evasion, antimagic, ethereal, refraction, hardening, carapace, disarm, thief |
| `sfx/status/crit`, `stun`, `armor_break` | крит, оглушение, сломанный щит или снятая защита |
| `sfx/waves/*` | старт, отсчёт, воздушная волна, волна пройдена |
| `sfx/economy/*`, `sfx/game/*` | золото, удача, кража золота, «золотой» враг, потеря жизни, победа, поражение, рекорд, начало и конец Испытания урона |
| `ambience/arena` | фоновая атмосфера (зациклена); во встроенном паке пусто — звучит только из звукового пака |
| `music/menu`, `build`, `combat`, `boss` | музыка состояний (зациклена, кроссфейд 1.5 с) |
| `music/victory`, `defeat` | короткие треки победы и поражения (играют один раз) |
| `sfx/enemies/<тип>/spawn`, `…/hurt` | появление врага и попадание по нему |
| `sfx/status/poison_tick`, `slow_apply` | отравление и замедление |
| `sfx/net/*` | лобби и «Гонка»: подключение, выход, готовность, старт матча, выбывший соперник |

## Музыка

Музыка — такие же события (`music/<состояние>`). Положите свой трек в `music/combat/` пака — он заменит встроенный. Зацикливание задаётся в манифесте (`"loop": true` у menu, build, combat, boss); для своих OGG/MP3/WAV игра включает петлю сама. Встроенные треки сгенерированы `tools/music_synth.gd` (22 кГц, моно).

## Звуковой браузер

Настройки → Звук → «Звуковой браузер»: все события, их источник (встроенный, ваш пак, замена через `fallback`) и кнопка ▶ для прослушивания. Поиск по id. Кнопка «Перезагрузить звуки» там же подхватывает новые файлы без перезапуска.

## Пространство

Боевые звуки панорамируются по положению на экране (левая или правая треть — шины `SFX_L` / `SFX_R` с панорамой ±0.45). Звуки интерфейса и музыка не панорамируются.

## Проверка

```bash
godot --headless --path . -- --audio-report
```

Для собранной игры:

```bash
"/Applications/Gem Tower Defense.app/Contents/MacOS/Gem Tower Defense" --headless -- --audio-report
```
