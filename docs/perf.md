# Производительность

Стресс-тест `tests/perf/stress.tscn` (§13 PROMPT.md): реальная игровая сцена с HUD, 60 башен вдоль пути,
на поле поддерживается ~300 врагов (волна 25, все архетипы, часть — элита), скорость 4×, vsync выключен.
Замер — 60 с после 4 с прогрева. Цели: ≥ 60 FPS на High; тик симуляции ≤ 2 мс при 300 врагах.

```bash
godot --path . res://tests/perf/stress.tscn -- --preset=high
```

## Разбивка кадра

Средние за кадр (`tests/perf/frame_probe.gd`): «Узлы» — `_process` всех узлов, включая шаги симуляции; «Хвост» — твины, таймеры,
отложенные вызовы и перерисовка `_draw` до начала отрисовки; «Отрисовка» — от `frame_pre_draw` до `frame_post_draw`
(с ожиданием GPU); «Прочее» — физика, ввод, аудио до следующего кадра.
