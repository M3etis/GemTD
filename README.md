# Gem Tower Defense

Лабиринтная tower defense на Godot 4 для macOS Apple Silicon: каждый раунд пять камней раскрываются в случайные гемы, один становится башней, остальные — стенами лабиринта.

**Версия 2.4.0** — единственный публичный релиз. Забег на 20, 42 или 62 волны с финальным боссом, рассчитанным на эту длину; четыре сложности; спец-башни, слейты, огранка и перенос башен; Испытание урона, Seed дня, локальная таблица лидеров с проверкой реплеем; LAN-«Гонка» до 4 игроков — в том числе бесконечная, где побеждает продержавшийся дольше. Визуальный стиль «Обсидиановая сокровищница»: арена из сканов камня с HDRI-светом, огранённые гемы на колоннах, 16 анимированных моделей врагов и боссов. Правила, цены и управление — в игре: Кодекс (G) → «Справка». Что вошло в релиз — [CHANGELOG.md](CHANGELOG.md), готовая сборка для macOS — в [Releases](https://github.com/M3etis/GemTD/releases).

В игре: 62 волны в два акта и 6 волн с боссами, 16 архетипов врагов и 12 трейтов, 8 гемов × 5 качеств, 13 спец-башен с тремя уровнями, 12 слейтов, 9 уровней удачи.

## Скачать и запустить сборку

1. Скачайте `GemTowerDefense-2.4.0-macOS-arm64.zip` со страницы [Releases](https://github.com/M3etis/GemTD/releases) и распакуйте.
2. Сборка подписана ad-hoc и не нотарифицирована, поэтому снимите карантин:

```bash
xattr -dr com.apple.quarantine "Gem Tower Defense.app"
```

3. Запустите `Gem Tower Defense.app`. Нужен Mac на Apple Silicon с macOS 11 или новее.

Сохранения, реплеи и рекорды прежних сборок не загружаются: лобби, сейвы и реплеи сверяют хеш данных баланса, а реплей проверяется пересимуляцией.

Если Finder не копирует `Gem Tower Defense.app` на внешний диск («имя слишком длинное или содержит недопустимые символы»), дело в диске, а не в имени: в приложении только короткие латинские имена файлов. Проверьте формат диска в Дисковой утилите (NTFS без драйвера открыт только для чтения; сторонние драйверы NTFS и ext4 не всегда принимают служебные атрибуты macOS) и запустите «Первую помощь». Проще всего перенести сам zip-архив и распаковать его уже на месте; копирование из Терминала покажет, на каком файле ошибка:

```bash
ditto "Gem Tower Defense.app" "/Volumes/<диск>/Gem Tower Defense.app"
```

## Требования

- macOS на Apple Silicon (M1 и новее), macOS 11+
- Godot 4.7.2 (проект открывается в 4.4+, но шаблоны экспорта должны совпадать с версией редактора)

### Установка Godot

Через Homebrew (команда `godot` сразу появляется в терминале: `/opt/homebrew/bin/godot` → `/Applications/Godot.app`):

```bash
brew install --cask godot
```

Или скачайте macOS-сборку (universal) с [godotengine.org/download/macos](https://godotengine.org/download/macos) и перетащите `Godot.app` в «Программы». CLI находится внутри приложения: `/Applications/Godot.app/Contents/MacOS/Godot`. Алиас `godot` для zsh:

```bash
echo 'alias godot="/Applications/Godot.app/Contents/MacOS/Godot"' >> ~/.zshrc && source ~/.zshrc
```

Проверка:

```bash
godot --version
```

Скрипты в `tools/` (они не видят алиасы) ищут `godot` в PATH, а если его нет — `/Applications/Godot.app/Contents/MacOS/Godot`; путь можно задать переменной `GODOT`.

### Первый импорт

После клонирования репозитория один раз импортируйте ресурсы (создаёт кеш `.godot/` и файлы переводов из `i18n/strings.csv`):

```bash
godot --headless --path . --import
```

## Запуск

Открыть проект в редакторе:

```bash
godot --path . --editor
```

Запустить игру:

```bash
godot --path .
```

Запустить игру на русском (язык по умолчанию берётся из системы, переключается в Настройки → Язык):

```bash
godot --path . -- --locale=ru
```

## Мультиплеер «Гонка» (2–4 игрока)

Главное меню → «Мультиплеер». Один игрок создаёт игру, остальные выбирают её в списке «Игры в вашей сети» или вводят IP хоста. Хост настраивает матч (сложность, seed, число волн — 20, 42 (первый акт, по умолчанию), все 62 или «∞», таймер раунда, «честные камни») и нажимает «Начать матч», когда все готовы. В матче на 20 и 42 волны последняя волна — финальная: её боссы элитные, финальный босс у цитадели снимает 20 жизней. **«∞» — бесконечная гонка:** после 62-й волны состав волн идёт по кругу с первой, но каждый круг врагов на 15 % больше, броня +1.5, скорость +4 % (до +25 %), а суммарное HP волны продолжает рост второго акта; побеждает тот, кто продержится больше волн. Выбранную хостом сложность видят все: в лобби, в верхней панели матча и в итогах. Каждый строит своё поле; волны стартуют одновременно; справа — панель игроков, клик по игроку показывает его поле (Esc — вернуться к своему). Там же видно золото соперников; клик по золоту соперника — передать ему золото. Если кто-то смотрит ваше поле, вы увидите сообщение. Enter — чат (кнопка 🙂 у поля ввода — эмодзи). Скорость матча задаёт хост, у остальных подсвечена текущая.

**Если вы выбыли,** матч продолжается без вас: откроется экран продолжения — ваш результат, живая таблица игроков, кнопки «Наблюдать: …» за каждым, кто ещё в игре, «Остаться на своём поле», «Меню» и «Выйти из матча» (хосту — с предупреждением: без хоста матч закончится у всех). Закрытый экран снова открывает Esc или «Экран матча» на плашке наблюдения. Итоги появятся сами, когда закончат все.

**Два экземпляра на одном Mac.** Из проекта — запустите в двух терминалах:

```bash
godot --path . -- --locale=ru
```

Из собранной игры (`-n` открывает второй экземпляр, а не переключает на первый):

```bash
open -n "build/Gem Tower Defense.app"
```

В первом окне «Мультиплеер» → «Создать игру», во втором — игра появится в списке, или «Прямое подключение» → `127.0.0.1`. Оба окна используют одни настройки, поэтому у второго игрока к имени добавится номер («Игрок 2»).

**Два Mac в одной сети.** Хост создаёт игру; второй игрок видит её в списке (UDP-маячок на порт 7778) или подключается по адресу, который хост видит в строке «Ваш адрес» (кнопка рядом копирует его; порт игры 7777/UDP). При первом хостинге macOS спросит:

- если включён брандмауэр — «Разрешить входящие сетевые подключения?» → «Разрешить» (для ad-hoc-подписанной сборки вопрос повторится после каждой пересборки);
- доступ к локальной сети (macOS 15+) — разрешите; включить позже: Системные настройки → Конфиденциальность и безопасность → Локальная сеть → Gem Tower Defense.

Версия игры и данные баланса у всех игроков должны совпадать — иначе лобби покажет понятную ошибку. Подробности и ограничения — [docs/NETCODE.md](docs/NETCODE.md).

## Первый запуск

«Новая игра» — сложность, **длина забега** (20, 42 или 62 волны: последняя — финальная; на 20 и 42 её боссы элитные, а финальный босс у цитадели снимает 20 жизней — пережить это можно только на Лёгкой; сила финала подобрана ботом под длину, в подсказке — кто ждёт в финале) и seed. Окно предлагает **обучение** — три раунда с подсказками: камни и «Оставить», «Объединить», рецепт спец-башни. Следующая волна по умолчанию ждёт кнопки «Начать волну» (Space); чтобы она стартовала сама после отсчёта, поставьте галочку «Автостарт» рядом со скоростью игры (или Настройки → Игра). Его можно пропустить и пройти снова (переключатель «Обучение» в окне новой игры). В обычной игре при первых событиях (воздушная волна, первый рецепт, босс, Покров) появляются короткие подсказки; их можно выключить в Настройки → Игра.

Все клавиши переназначаются в Настройки → Управление. Доступность (палитра для дальтоников, масштаб интерфейса и текста, вспышки, подписи к звукам) — Настройки → Доступность.

## Слейты

Плиты из оригинальной Gem TD: лежат на земле, путь не перекрывают и бьют, замедляют или оглушают врагов рядом либо усиливают башни аурой. Если среди пяти камней раунда есть пара «гем III + нужный гем II», в фазе выбора появится кнопка «Сделать: …». Слейт лежит отдельным слоем: камень и башню можно ставить прямо на него — при расстановке клик по клетке со слейтом ставит камень, а над камнем, стеной или башней на слейте светится его значок. Клик по слейту в остальных фазах (или «Под ней слейт: …» в панели стены или башни над ним) открывает его панель: «Переложить — N золота» — затем клик по любой клетке без другого слейта (на путь, под стену, под башню); перекладывать можно сколько угодно раз, каждый перенос на 5 золота дороже предыдущего; «Объединить → …», если на поле есть пара для составного; «Продать». Рецепты и эффекты — Кодекс, вкладка «Слейты».

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ | поставить камень / выбрать гем или башню |
| Наведение на поле | превью нового пути и изменения его длины |
| 1–5, клик по камню или карточке | выбрать гем в панели выбора (повторный клик гем не оставляет) |
| «Оставить» | оставить выбранный гем — только этой кнопкой |
| Space | начать волну |
| «Оставить на II» и т. п. | оставить выбранный гем на одно качество ниже (для рецептов, где нужно именно оно) |
| C | объединить одинаковые гемы (×4, иначе ×2); повторы среди кандидатов помечены на поле значком «×N» |
| F | сплавить спец-башню (для выбранного гема или из башен на поле) |
| B | разбить выбранную стену |
| G | Кодекс: рецепты, уровни спец-башен, гемы, враги, трейты; булавка у рецепта — отслеживать его (до четырёх сразу) |
| Tab | прогноз трёх ближайших волн (в «Гонке» — переключение между полями соперников) |
| ЛКМ по башне / стене | панель башни (приоритет цели, улучшение, огранка, перенос, продажа) / разрушение стены |
| «Огранить» (панель башни) | +3 % урона этой башни за уровень, до 10 уровней; цена ×1.55 за уровень (40, 62, 96 … ≈ 5.7 тыс. за все десять), при продаже — 60 % потраченного. Башням поддержки без урона (Маяк-Линза, Боевое знамя, Морозный Колодец) недоступна; при сплаве огранка компонентов переходит в спец-башню |
| «Перенести» (панель башни) | затем клик по стене или башне — меняются местами (лабиринт тот же), по пустой клетке — башня переезжает (путь пересчитывается); 10 золота, каждый следующий перенос на 10 дороже |
| ↑ / ↓ у «Журнала» | свернуть или развернуть журнал событий (запоминается) |
| U | повысить удачу |
| Z / X | скорость игры − / + (1×, 2×, 4×) |
| «Автостарт» (верхняя панель) | следующая волна стартует сама после отсчёта; без галочки ждёт «Начать волну» |
| P | пауза |
| H | показать радиусы всех башен |
| Alt (удерживать) | HP всех врагов |
| R | рестарт с тем же seed (с подтверждением) |
| Esc | меню паузы / закрыть окно |
| Enter | чат в «Гонке»: открыть, отправить; Esc — закрыть |
| WASD / стрелки, колесо, средняя кнопка | камера: панорама и зум; Home — сброс |
| Ctrl/Cmd + колесо (или прокрутка тачпада и Magic Mouse), Ctrl/Cmd + «+» / «−», Ctrl/Cmd + 0 | зум камеры от крупного плана (~8 клеток по высоте) до всего поля с запасом; 0 — исходный зум |

## Проверка

Тесты — 205 штук: RNG, пути, фаза строительства, урон, волны (два акта, поздний рост HP, длины забега и финал, бесконечный режим), перенос башен и слейтов, огранка, экран продолжения «Гонки» и эмодзи, сложности (разгон HP, Панцирь, Испытание урона, порядок уровней), трейты, боссы и полоса HP босса, спец-башни, Испытание урона, стратегии бота, очки, реплеи, подмена звуков, учёт голосов, модели врагов, хранение (порча настроек, сейвов, реплеев, таблицы лидеров) и изоляция экспорта (игра не ссылается на `tests/` и `tools/`).

```bash
godot --headless --path . -s res://tests/run_all.gd
```

Один файл тестов:

```bash
godot --headless --path . -s res://tests/run_all.gd -- --filter=test_persistence
```

Компиляция всех скриптов с автозагрузками:

```bash
godot --headless --path . -- --check-scripts
```

Автопрогон бота (печатает итог и контрольную сумму; два запуска с одним seed должны совпасть):

```bash
godot --headless --path . -- --autoplay --seed=42 --strategy=maze
```

Стратегии бота: `maze`, `specials`, `damage`, `control`, `antiair`, `slates` (и `random` как базовая линия). `--waves=N` ограничивает число волн (20 и 42 — забеги с финалом), `--difficulty=easy|normal|hard|extreme`.

Баланс: 6 стратегий × N seed × сложности, параллельно процессами Godot. Пишет CSV и сводку в `docs/balance/` (62 волны, 20 seed, все сложности — около 40 минут на 10 ядрах):

```bash
godot --headless --path . -s res://tools/balance_sim.gd -- --seeds=20 --difficulty=easy,normal,hard,extreme --tag=v2_3
```

Длина забега и огранка: `--waves=20` / `--waves=42` гоняют короткие забеги с финальным боссом, `--polish` — бот тратит лишнее золото на огранку (мера её влияния на баланс):

```bash
godot --headless --path . -s res://tools/balance_sim.gd -- --seeds=20 --waves=20 --difficulty=easy,normal,hard,extreme --no-test --tag=len20
```

Разбор одного забега по волнам (жизни, золото, удача, башни, бой с боссом по секундам):

```bash
godot --headless --path . -s res://tools/balance_sim.gd -- --trace=maze:1001
```

Посмотреть, как играет бот, в окне:

```bash
godot --path . -- --autoplay --visual --seed=42
```

Отчёт по звуковым событиям:

```bash
godot --headless --path . -- --audio-report
```

Скриншоты для самопроверки (`menu`, `build`, `draft`, `combat`, `stress` — 200+ врагов, `boss` — финальный босс, лучше с `--difficulty=easy`, `damagetest` — Испытание урона, `vfx` — крупный план боя, `forge` — анимация сплава, `settingsvideo` — настройки графики, `raceout` — экран продолжения «Гонки» после выбывания, `codexhelp` — Кодекс, «Справка», `wavetraits`, `codextraits`, `results`, `settings`, `leaderboard`, `lbdetail`, `newgame`, `tower`, `codex`, `codexmenu`, `replay`, `lobby`, `credits`, `licenses`) сохраняются в `docs/screenshots/` (из собранной игры — в `~/Library/Application Support/GemTowerDefense/dev/screenshots/`). `saveload` дополнительно сохраняет забег, загружает его через игровую сцену и сверяет контрольную сумму:

```bash
godot --path . -- --screenshot=draft --locale=ru
```

Стресс-тест производительности (60 башен, ~300 врагов, скорость 4×, 60 с; итог и разбивка кадра — в `docs/perf.md`, `--seconds=N` укорачивает замер):

```bash
godot --path . res://tests/perf/stress.tscn -- --preset=high
```

Пресет графики для любого запуска перекрывается флагом `--preset=low|medium|high|ultra`; запасной рендер — `--rendering-method gl_compatibility`.

Автотест мультиплеера (два headless-процесса с ботами, матч на 5 волн, ожидается `MP-OK` у обоих):

```bash
tools/mp_selftest.sh 5
```

То же для собранной игры:

```bash
GTD_BIN="build/Gem Tower Defense.app/Contents/MacOS/Gem Tower Defense" tools/mp_selftest.sh 5
```

Перезапечь модели врагов в VAT — нужно окно, без `--headless`. Исходники в репозиторий не входят: скачайте их по ссылкам из `SOURCES` в `tools/bake_enemy_vat.gd` (Sketchfab — GLB, Universal Animation Library — `Unreal-Godot/UAL1_Standard.glb` из бесплатной версии Standard) в `art_src/models/<папка из MODELS>/`. Бейкер сам доворачивает скелет-источник ретаргета и замеряет шаг цикла.

```bash
godot --path . -s res://tools/bake_enemy_vat.gd
```

Одну модель: `-- --only=char_enemy_pachy_01`. Превью рядовых, боссов и кадров одной модели — `godot --path . res://tools/art_preview.tscn -- --enemies --enemy=normal` (снимки в `docs/art/after/`).

Спрайты частиц и флипбуки эффектов (исходники Kenney и Unity Labs — в `art_src/vfx/`) — `godot --headless --path . -s res://tools/bake_art_assets.gd -- --vfx`. Превью эффектов в ряд — `-- --vfx`, портреты врагов для Кодекса — `-- --portraits` (оба через `tools/art_preview.tscn`, с окном).

Перегенерировать встроенные процедурные звуки:

```bash
godot --headless --path . -s res://tools/sfx_generator.gd
```

## Где хранятся данные игрока

Папка одна и та же для запуска из проекта и для собранного `.app`:

```bash
open "$HOME/Library/Application Support/GemTowerDefense"
```

| Путь | Что |
|---|---|
| `settings.cfg` | настройки и переназначенные клавиши |
| `saves/autosave.json`, `saves/slot1–3.json` | автосохранение (начало каждого раунда) и ручные сохранения (Пауза → Сохранить) |
| `leaderboard.json` (+ `.bak`) | таблица лидеров; испорченный файл откладывается в `.corrupt`, записи берутся из `.bak` |
| `replays/*.gtdr` | реплеи всех завершённых забегов |
| `profiles/default.json` | профиль игрока |
| `sound_packs/custom/` | ваш звуковой пак — создаётся при первом запуске вместе с `README.txt` |
| `logs/godot.log` | журнал последнего запуска (прошлые — рядом, с датой) |
| `dev/` | автопрогоны бота, тесты и скриншоты (не попадают в вашу таблицу) |

Рекорд с реплеем можно выгрузить в файл `.gtdx` (Таблица лидеров → запись → «Экспорт», по умолчанию в «Загрузки») и отправить другу: при импорте он принимается только после успешной пересимуляции.

**Замена звуков** — без пересборки игры: положите свои файлы в `sound_packs/custom/<событие>/` или в папку `audio_override/` рядом с `Gem Tower Defense.app`. Форматы, список событий и приоритеты источников — [docs/AUDIO_MODDING.md](docs/AUDIO_MODDING.md).

## Сборка macOS (arm64)

Проверено на Godot 4.7.2: результат — `build/Gem Tower Defense.app` (≈300 МБ, из них `.pck` — 225 МБ, в основном текстуры ремейка; zip — ≈180 МБ; только arm64, ad-hoc-подпись).

**1. Шаблоны экспорта той же версии, что и редактор.** В редакторе: Editor → Manage Export Templates… → Download and Install. Или из терминала (архив 1,28 ГБ; для macOS нужны только `macos.zip` и `version.txt`):

```bash
curl -L -o /tmp/godot_templates.tpz https://github.com/godotengine/godot/releases/download/4.7.2-stable/Godot_v4.7.2-stable_export_templates.tpz
```

```bash
mkdir -p "$HOME/Library/Application Support/Godot/export_templates/4.7.2.stable" && unzip -j -o /tmp/godot_templates.tpz "templates/macos.zip" "templates/version.txt" -d "$HOME/Library/Application Support/Godot/export_templates/4.7.2.stable"
```

**2. Шаблон arm64.** Официальный `macos.zip` содержит только universal-бинарник, а пресет «macOS» собирает arm64 и ждёт отдельный arm64-шаблон. Скрипт вырезает arm64-срез через `lipo` и кладёт его в `build/templates/macos_arm64.zip` (один раз после установки шаблонов):

```bash
tools/make_arm64_template.sh
```

**3. Экспорт.** Пресет «macOS» уже в репозитории (`export_presets.cfg`): архитектура arm64, подпись «Built-in (ad-hoc only)», без нотаризации, `NSLocalNetworkUsageDescription` для LAN, исключены `tests/`, `tools/`, `docs/`.

```bash
godot --headless --path . --export-release "macOS" build/GemTowerDefense.zip
```

**4. Распаковка и первый запуск.** Сборка не нотарифицирована, поэтому снимите карантин (особенно если архив скачан или передан через AirDrop/мессенджер):

```bash
cd build && unzip -o GemTowerDefense.zip && xattr -dr com.apple.quarantine "Gem Tower Defense.app"
```

```bash
open "build/Gem Tower Defense.app"
```

Проверка подписи и архитектуры:

```bash
codesign --verify --deep --strict "build/Gem Tower Defense.app" && lipo -info "build/Gem Tower Defense.app/Contents/MacOS/Gem Tower Defense"
```

Самопроверка собранной игры без окна (компиляция всех скриптов из `.pck` и бот-прогон с той же контрольной суммой, что и в редакторе):

```bash
"build/Gem Tower Defense.app/Contents/MacOS/Gem Tower Defense" --headless -- --check-scripts
```

```bash
"build/Gem Tower Defense.app/Contents/MacOS/Gem Tower Defense" --headless -- --autoplay --seed=42 --strategy=maze
```

Universal-сборка (Intel + Apple Silicon, примерно на 85 МБ больше) не требует шага 2: в `export_presets.cfg` поставьте `binary_format/architecture="universal"` и очистите `custom_template/debug` и `custom_template/release`.
